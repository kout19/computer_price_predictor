# Laptop Price Prediction System

An end-to-end machine learning web application that predicts laptop prices using hardware specifications.

## Features

- Predict laptop prices
- Interactive dashboard
- Feature importance visualization
- Model comparison
- Dataset insights
- Responsive UI
- REST API
- FastAPI backend
- React frontend

## Tech Stack

Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- TanStack Query

Backend

- FastAPI
- Scikit-learn
- Pandas
- Joblib
- Uvicorn

ML

- Gradient Boosting Regressor
- StandardScaler
- OneHotEncoder
